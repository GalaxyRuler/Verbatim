# FAQ

**Is Verbatim free?**
Yes — free and open source. No subscription, no account. The full source is on [GitHub](https://github.com/GalaxyRuler/Verbatim).

**Does my voice leave my device?**
Never. Capture, transcription, and the final text all happen locally. No cloud, no telemetry. See [Privacy](privacy.md).

**Why does my OS warn on first launch?**
The desktop builds are unsigned. On Windows choose _More info → Run anyway_; on macOS right-click the app → _Open_. One time only. The Android APK is signed but distributed outside Google Play, so Android may warn about installing from an unknown source — allow your browser or file manager to install it to sideload.

**Does it work offline?**
Yes. Once a model is downloaded, Verbatim needs no network connection.

**Can I change the hotkey or the model?**
Yes — set any global hotkey and switch between open models in Settings. See [Getting started](getting-started.md) and [Models](models.md).

**Which platforms are supported?**
Windows (x64), macOS (Apple Silicon), Linux (Ubuntu / Debian), and Android (universal APK, sideloaded from the Releases page).
